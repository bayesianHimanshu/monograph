## What this means for the PoV

* **Identity is the lever.** Removing the identity layer cost 0.53 of T3+T4 accuracy on average for free-form arms and 0.79 for tools arms (claude-haiku-5-5, descriptions on; P1 confirmed). Without the layer, free-form SQL and Cypher reached 0.47 and 0.44 on those questions, the tools 0.20 and 0.21: a free-form agent can partly rebuild identity from names and codes (pattern matching, padding an NDC), while a fixed tool set that resolves exactly cannot. Identity is data both stores carry; how much an agent loses without it is what P1 measures. Without the layer, by the identity a question needs: encoded in names or codes (salt forms, 11-digit NDCs): free-form 0.92, tools 0.46; recorded only in a crosswalk (RxCUI, brand to generic): free-form 0.01, tools 0.00; firm aliases: free-form 0.42, tools 0.11.
